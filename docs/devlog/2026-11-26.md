- 실제 TCP로 이동한 원격 Bob을 다시 촬영해 README의 조준 보행 GIF를 무광 머티리얼과 복구된 월드가 보이는 영상으로 갱신했다.

## ShooterPack 전진 걷기

- 서버와 동일한 `DeathWish.Protocol.dll`을 설치했다. Unity는 기존 타임라인을 따라 서버가 보내는 `walk forward.fbx` 기반 보행 각도를 다리에 적용하고, 상체는 기존 조준 클립을 사용한다.
- Unity 6000.3.11f1 Play 모드에서 같은 서버 시각의 Bob 양쪽 허벅지와 정강이 회전을 정지·보행 249개 샘플로 확인했다. 왼손 지지점 최대 오차는 1.79mm였다. 실제 TCP 서버에서 원격 Bob이 걷는 장면으로 [README의 GIF](../media/shooter-aim-walk.gif)를 갱신했다. 고정된 골반과 발목 때문에 원본 FBX의 발바닥 접지는 정확히 재현되지 않는다.
- 별도 Unity 검사에서 평지 위 Bob 스킨의 최저점을 측정했다. 정지 시 바닥과 일치했고 보행 주기 중에는 약 0.6–14.9cm 위에 있었다.

## 보행 상태로 ShooterPack Animator 재생

- Unity는 18번 스냅숏으로 받은 위치·방향·누적 보행 주기를 100ms 지연 타임라인에서 함께 보간한다. Bob의 Animator가 주기에 맞춰 ShooterPack의 전진 걷기 클립을 재생하고 정지 시 대기 자세로 전환한다. 루트 모션은 끄고 단색 무광 머티리얼과 상체 조준을 적용한다. 이동, 점프, 충돌과 피격 판정은 서버가 처리한다.
- 서버 설치 원본과 클라이언트의 재생 스크립트, 클립·메타데이터, 배포 DLL을 동기화했다. Unity 6000.3.11f1 API 컴파일, 별도 프로젝트의 Play 모드 검사 및 실제 TCP 원격 보행 검사를 통과했다. Bob 모델이 없는 경우 박스 리그 표시도 별도 실행으로 확인했다. 정지·보행·정지 전환의 249개 샘플에서 골반과 양쪽 다리·발목·발가락이 클립과 일치했고 막대 중심선과 왼손 지지점 간 최대 오차는 1.79mm였다. [README GIF](../media/shooter-aim-walk.gif)를 원격 Bob의 새 재생 화면으로 갱신했다.
- 서버의 보행 주기는 기존의 5m당 한 주기를 사용한다. 원본 FBX가 한 주기에 전진한 거리는 약 1.81m이므로 애니메이션의 발이 수평으로 미끄러져 보일 수 있다.
- 평지 보행 샘플에서 스킨의 본 행렬과 바인드 포즈로 계산한 Bob 메시 최저점은 서버 바닥 기준 −7.44~+7.25mm였다. 별도의 발 IK는 적용하지 않았다.

## 카메라 방향 조준

- 정지 중에도 이동 입력과 카메라 방향을 함께 전송한다. 로컬 Bob은 같은 프레임의 시선을 따르고, 원격 Bob은 서버가 전달한 수평각과 수직각을 위치와 같은 100ms 지연 타임라인에서 보간한다. 좌우로는 몸 전체를 돌리고 위아래로는 조준 클립을 적용한 뒤 척추를 회전시켜 막대가 카메라 레이와 평행하게 놓인다.
- 걷기는 기존 ShooterPack 전진 클립을 사용한다. 옆이나 뒤로 이동해도 시선은 카메라를 따른다. 어깨 전환은 카메라 위치에 적용되고, 클릭 시점의 카메라 레이와 막대 끝을 각각 피격 요청과 화면 궤적에 사용한다.
- Unity 6000.3.11f1 컴파일과 Play 모드, 같은 방의 실제 TCP 클라이언트 두 개로 정지·이동 중 조준을 확인했다. 249개 샘플에서 막대와 시선 간 최대 각도 오차는 0.028°, 왼손과 막대 사이 최대 거리는 1.79mm였다. 모델이 없는 설치본의 대체 표시도 통과했다. 두 README의 [테스트 GIF](../media/shooter-aim-walk.gif)를 새 원격 조준 장면으로 갱신했다.
- 정지 자세에서 발이 서버 바닥보다 0.946m 위에 보이는 문제를 재현했다. 정지 클립을 실제 클라이언트 FBX의 기본 자세에서 새로 생성한 뒤 측정한 발바닥 높이는 정지 시 0.0mm였다. 정지·보행 클립의 샘플은 −6.0~+4.3mm였고 두 클립을 절반씩 혼합한 전환 샘플에서는 최대 5.55cm 바닥에 들어갔다. 하체는 옆걸음과 뒷걸음에도 기존 전진 클립을 사용한다.

## Bob의 AR 소총 장착

- 플레이어와 원격 Bob에 에셋 저장소의 AR 모델을 장착했다. 기존 단색 캐릭터 위에 원본 크기의 소총과 PBR 재질을 표시한다. 조준 대기·걷기 중 오른손이 손잡이를 잡고 왼손은 앞쪽 지지점에 맞춰진다. 카메라와 총열 방향을 일치시키고 클릭한 순간의 총구 위치를 궤적 시작점으로 저장한다.
- Unity 6000.3.11f1 Play 모드에서 실제 AR 메시와 재질을 로드해 249개 자세에서 두 손의 접점과 총구 방향을 검사했다. 실제 TCP로 같은 방에 들어간 로컬·원격 캐릭터의 장착, 제자리 조준·이동 및 클릭 시점의 궤적을 확인하고 양쪽 [README GIF](../media/shooter-aim-walk.gif)를 교체했다.

## 좌클릭 사격과 원격 반동

- ShooterPack 아카이브의 FBX 50개를 확인했다. 전용 발사 클립이 없어 사용자 선택에 따라 `idle aiming.fbx` 상체 자세에 짧은 반동을 합성한다. 양손과 소총이 함께 움직이며 하체는 기존 보행 주기를 유지한다.
- 로컬 클릭에서 카메라 레이와 그 순간의 총구를 먼저 기록한 뒤 같은 프레임에 반동을 시작한다. Unity는 방 입장 모드 4에서 서버의 원격 발사 이벤트를 받는다. 명중과 빗나감 모두 반동을 표시하고 다음 클릭으로 재생을 다시 시작한다.
- Unity 6000.3.11f1 컴파일·Play 모드·실제 TCP 검사를 통과했다. 반동은 클릭 프레임에 시작해 약 0.24초 뒤 원래 자세로 돌아왔고 테스트에서 총구가 최대 9.98° 들렸다. 이동 중 하체와 양손 소켓, 연속 클릭, 자신에게 돌아오는 중복 재생 방지, 원격 관찰과 캡처 시점의 레이를 확인했다. 늦게 도착한 두 이벤트(350·400ms)도 각각 재생됐다. 양쪽 README에 실제 원격 발사 7회가 보이는 [녹화](../media/shooter-aim-walk.gif)를 반영했다.
